සීමාවක් ප්‍රකාශ කර නොමැත.මේ පිළිබඳව පවතින වත්මන් තත්ත්වය සහ කාලසීමාවන් පැහැදිලිව පහත පරිදි වේ:⏳ 1. වත්මන් නීතිමය සහ තාක්ෂණික තත්ත්වය (Current Timeline)රජයේ සහ IRD සැලසුම: දැනට පවතින තත්ත්වය අනුව, මුළු දිවයිනම ආවරණය වන පරිදි සම්පූර්ණ ක්‍රියාවලිය නිල වශයෙන් අවසන් කිරීමට සහ සියලුම VAT ලියාපදිංචි ව්‍යාපාර මේ සඳහා ඇතුළත් කර ගැනීමට වසර 2ක පමණ කාලයක් (2026 සිට ඉදිරියට) ගතවනු ඇතැයි ඇස්තමේන්තු කර ඇත.පිරිවිතර (Specifications) නිකුත් කිරීම: ඩිජිටල් ආර්ථික අමාත්‍යාංශය (Digital Economy Ministry) මඟින් මේ සඳහා අවශ්‍ය අවසන් මෘදුකාංග සහ දෘඩාංග පිරිවිතරයන් (Software & Hardware Specifications) ලබාදෙන තෙක් IRD ආයතනය බලා සිටී. එම පිරිවිතරයන් නිල ගැසට් නිවේදනයක් මඟින් නිකුත් කිරීමට නියමිතය.📅 2. ගැසට් නිවේදනය නිකුත් වූ පසු කාලයමාස 3ක සහන කාලය: IRD ආයතනය විසින් අනුමත POS යන්ත්‍ර පිළිබඳ අවසන් ගැසට් නිවේදනය නිකුත් කළ පසු, ව්‍යාපාරවලට IRD අනුමත POS පද්ධතියක් ස්ථාපනය කර ගැනීමට මාස 3ක (දින 90ක) කාලයක් ලබාදීමට නීතියෙන් ප්‍රතිපාදන සලසා ඇත.💻 3. දැනට ක්‍රියාත්මක වන පද්ධති (Pilot Phase)දැනට IRD එක මඟින් සිදු කරන්නේ තෝරාගත් මහා පරිමාණ සහ අපනයන ව්‍යාපාර කිහිපයක් සමඟ පර්යේෂණ මට්ටමින් (Pilot Program/API Integration) සෘජුව RAMIS පද්ධතියට සම්බන්ධ කිරීම පමණි.💡 ඔබ දැන් කළ යුත්තේ කුමක්ද?POS සැපයුම්කරුගෙන් විමසන්න: ඔබ POS පද්ධතියක් මිලදී ගැනීමට බලාපොරොත්තු වන ආයතනයෙන් (POS Service Provider) ඔවුන්ගේ පද්ධතිය ඉදිරියේදී IRD (RAMIS 2.0) පද්ධතියේ WEB API සමඟ සෘජුව සම්බන්ධ වීමට (Real-time data integration) තාක්ෂණිකව සූදානම්ද කියා අනිවාර්යයෙන්ම විමසන්න.නිල නිවේදන පිළිබඳ අවධානයෙන් සිටින්න: IRD ආයතනය විසින් ඉදිරියේදී නිල වශයෙන් අනුමත කරනු ලබන POS මෘදුකාංග සහ යන්ත්‍ර ලේඛනය (Approved Vendor/Device List) RAMIS Web API එක සමඟ සෘජුව සම්බන්ධ වීම (Real-time Integration)ඔබේ POS පද්ධතියට, පාරිභෝගිකයෙකු මුදල් ගෙවූ සැනින් (Real-time), එම විකුණුම් දත්ත (Sales Data) සහ VAT තොරතුරු IRD හි RAMIS (Revenue Administration Management Information System) පද්ධතිය වෙත Web API එකක් හරහා ස්වයංක්‍රීයව යැවීමේ හැකියාව තිබිය යුතුය.මෙයට අදාළ API Documentation සහ Guidance දැනටමත් IRD එක මඟින් තෝරාගත් මෘදුකාංග සමාගම් වෙත ලබා දෙමින් පවතී.📄 2. නව නිල බදු ඉන්වොයිස් ආකෘතිය (Mandatory Invoice Format)ඔබේ POS පද්ධතියෙන් නිකුත් කරන බිල්පත (Invoice) IRD නීති රීතිවලට අනුව සකස් විය යුතුය. එහි අනිවාර්යයෙන්ම:දිනය: MM/DD/YYYY ආකෘතියට තිබීම.අනුක්‍රමික අංකය (Serial Number): YYMMM_DD/DEPT_SERIAL වැනි IRD එකෙන් නියම කළ නිවැරදි ව්‍යුහයකට තිබීම.TIN අංක: විකුණුම්කරුගේ සහ ගැනුම්කරුගේ (B2B නම්) TIN අංක සඳහන් වීමට ඉඩ තිබීම.ශත අගයන් රහිත වීම: මුළු මුදල සම්පූර්ණ රුපියල්වලින් (Whole Rupees) පමණක් පෙන්විය යුතුය.🔒 3. දත්ත වෙනස් කළ නොහැකි වීම (Data Security & Tamper-Proof)POS පද්ධතිය තුළ සටහන් වන විකුණුම් දත්ත පසුකාලීනව මකා දැමීමට හෝ වෙනස් කිරීමට (Edit/Delete) පරිශීලකයාට (Merchant) නොහැකි වන පරිදි පද්ධතිය සුරක්ෂිත (Secured POS) විය යුතුය. සෑම ගනුදෙනුවකටම පැහැදිලි විද්‍යුත් විගණන මඟක් (Electronic Audit Trail) තිබීම අනිවාර්ය වේ.📱 4.
